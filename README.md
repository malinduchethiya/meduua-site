# MEDUUA® — Premium Business Website UI

A responsive editorial agency / web design business website concept in plain HTML, CSS and JavaScript.

## Open

Open `index.html` in your web browser. No npm, build tools, or server are required. The bundled portfolio screenshot is at `assets/salt-stone-preview.jpg`. Google Fonts load from the internet when available; system fallbacks are included.

## Working UI features

- Desktop and mobile navigation.
- Smooth anchor navigation and an animated category ticker (reduced motion supported).
- Portfolio filtering and detailed project popups.
- Expandable service and FAQ sections.
- Pricing buttons that preselect the package in the enquiry form.
- Project enquiry form that opens a prefilled WhatsApp message to +94 70 309 0130.
- Email and WhatsApp contact links.
